### Maintainer

- **[kvdock](https://github.com/zisam-glitch/kvdock)**: Universal key-value and caching engine with zero-dependency core and pluggable storage adapters (TypeScript / Node.js).
- **[kvdock-rs](https://github.com/zisam-glitch/kvdock-rs)**: High-performance, zero-dependency caching layer for Rust with thread-safe LRU eviction and monotonic TTL expiration.
- **[kvdock-go](https://github.com/zisam-glitch/kvdock-go)**: Generic key-value caching library for Go with atomic telemetry and cache-aside primitives.
- **[kvdock-swift](https://github.com/zisam-glitch/kvdock-swift)**: Actor-isolated, concurrent caching layer for Swift 6 with monotonic `ContinuousClock` TTL enforcement.
- **[kvdock-kt](https://github.com/zisam-glitch/kvdock-kt)**: Thread-safe, generic key-value caching library for Kotlin and the JVM with $O(1)$ LRU eviction.
